# Reporting back

Another session started you, and Dray sends your final message of each turn to it automatically. Don't send that message yourself with `dray session send`; end each turn with what that session needs to know.

# Proof

When your work changes something a person can see, record a short video of the finished work and put its path in your final message, so the session that started you can pass it on. Record only where it touches nothing of the user's own: a sandbox or other remote machine, a VM, an iOS simulator, or the session browser for a web app or site (`dray browser record`). Never drive the user's own screen to record unless the user asks. When none of those can run it, say so instead.
