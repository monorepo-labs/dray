Dray runs the coding agent CLIs you already use (Claude Code, Codex, pi, fx and Grok Build) in one chat window. It is free and open source, and runs on the subscriptions you already have. Dray installs no agent and stores no agent login: each agent keeps its own.

## What you can do

- **Run many agents at once.** Each conversation is a session in the sidebar. Sessions keep running when you switch away, and when you quit the app.
- **Give each task its own checkout.** A session can work in its own git worktree, so two agents never edit the same files.
- **Steer the agent as it works.** Change the model, effort, fast mode and permission mode from the composer. Answer permission and question cards in the transcript.
- **Write prompts with context.** Slash commands, `@` file mentions, `#` issue tags, images and files, and local dictation.
- **Let agents fan out.** The `dray` command line lets an agent start sessions of its own, message them, link issues, and drive a browser.
- **Work from issues.** Connect Linear or GitHub, browse your issues, and tag them in a prompt.
- **Connect a server.** Add a Linux box over SSH and run your agents there, driven from the Mac app.
