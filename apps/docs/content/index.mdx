Dray runs the coding agent CLIs you already use (Claude Code, Codex, pi, fx, Grok Build and OpenCode) in one chat window. It runs on a Mac, with a Linux version in beta. It is free and open source, and runs on the subscriptions you already have. Each agent keeps its own login: Dray stores none.

## What you can do

- **Run many agents at once.** Each conversation is a session in the sidebar. Sessions keep running when you switch away, and when you quit the app.
- **Run your work from a bot.** A bot is one chat that starts tasks in any project, keeps them moving, and comes back only when something needs you, with a merge card when a pull request is ready. Dray Bot is there from the start. See [Bots](/using-dray/bots).
- **Give each task its own checkout.** A session can work in its own git worktree, so two agents never edit the same files.
- **Steer the agent as it works.** Change the model, effort, fast mode and permission mode from the composer, or move a task to another agent. Answer permission and question cards in the transcript.
- **Write prompts with context.** Slash commands, `@` file mentions, `#` issue and pull request tags, images and files, and local dictation.
- **Let agents fan out.** The `dray` command line lets an agent start sessions of its own, message them, link issues, and drive a browser.
- **Work from issues and pull requests.** Connect Linear or GitHub and browse your issues. The Pull requests page lists every open PR involving you, and starts a task from any of them. See [Pull requests](/using-dray/pull-requests).
- **Connect a server.** Add a Linux box over SSH and run your agents there, driven from the app.
- **Follow along on your iPhone.** The [Dray app for iPhone](https://apps.apple.com/app/id6824145317) reads and drives your sessions through your Mac's remote access or a server. Pair it from Settings → Servers. See [Remote access](/reference/remote-access).
