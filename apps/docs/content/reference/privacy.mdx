This is Dray's privacy policy. It covers the Dray desktop app, the Dray app for iPhone and iPad, Dray accounts, and drayhq.com with these docs. "We" and "us" here mean Dray.

Last updated: 19 November 2026.

In short:

- Your prompts, code, transcripts and files stay on your own machines.
- The desktop app sends a few [anonymous usage events](#analytics-in-the-desktop-app). You can [turn them off](#turn-analytics-off).
- The [iPhone and iPad app](#the-iphone-and-ipad-app) collects nothing.
- A [Dray account](#your-dray-account) holds your name, email address and the machines you sign in on.
- We sell nothing, show no ads and do not track you across other apps or sites.

## Analytics in the desktop app

Dray sends a small set of anonymous usage events, so we can see which builds are in use, which features get used and where the app breaks. Your prompts, code, conversations, file paths, session titles and error messages never leave your machine through analytics. Analytics is on, and Settings has no switch for it.

## Turn analytics off

Set `DRAY_NO_ANALYTICS` to any value in the environment Dray starts from. Dray then sends nothing, from the app or from the background server on your Mac, since the app passes the variable on to it. See [Environment variables](/reference/data#environment-variables) for how to start the app with one.

Older versions had a **Share basic analytics** switch in Settings. A choice saved there is no longer read.

## The install id

Events are tied to a random id for this install, not to you. It is created with the first event and stored in `~/.dray/settings.json`.

## What is sent

Every event carries the same few facts about the build:

| Property | Example |
|---|---|
| `app_version` | `0.28.1` |
| `os`, `arch` | `macos`, `aarch64` |
| `is_debug` | `false` |
| `source` | `app` |

PostHog, the service that receives events, keeps the IP address each event comes from, and uses it to tell the country.

Then each event adds its own:

| Event | When | Adds |
|---|---|---|
| `app_started` | Each launch | Nothing more. |
| `active_day` | At most once a day: on launch, when Dray comes to the front, when you send a message, or when you use Dray Island | Nothing more. Messages agents send each other do not count. |
| `session_started` | You create a session | Agent, model, effort, permission mode, whether fast mode is on, whether it uses a worktree, whether another session started it, and where it runs: `local` or `remote` (below). |
| `feature_used` | A feature works | Which feature, from a fixed list (below). |
| `error` | Something breaks | Where it broke, never what it said (below). |

`feature_used` names one of: `dictation` (with the dictation model's id, and where you dictated: `app`, `island` or `phone`), `island_open` (you opened Dray Island), `island_send` (you sent a message from it), `island_card` (you answered a permission or question card from it), `fork`, `pr_merged`, `linear_connected`, `space_created`, `worktree_deleted`, `settle`, `unsettle`, `pin`, `unpin`, `set_aside`, `unset_aside`, `handoff_commit`, `handoff_pr`, `handoff_runServer`, `handoff_custom` (you pressed a button of your own, never its label or prompt), `browser_open` (you opened a page in the browser, with `localhost` or `site` and never the address), `boat_resumed`, `boat_extended` (with how many minutes), `remote_access`, `share`, `server_added` and `server_connected`. The last three add how: `app` or `cli` for a share, `ssh` or `address` for a server. Never the port, the address or the server's name. `server_connected` is sent at most once a day per kind.

## What is never sent

- Your prompts, the agent's replies, and anything else in a transcript.
- Code, file names and file paths.
- Session titles, project names, branch names, issue titles.
- Server names and addresses, ports and links.
- The text of any error message.
- Screens or recordings. Session recording and click tracking are off.

## Error reports

When Dray breaks, the `error` event says where, in a form that cannot carry your data:

- **A crash in the app's core:** the file and line in Dray's own source code, and the thread's name. Not the crash message, since that can contain a path.
- **An agent line Dray could not read:** which agent, and at which step. Not the line itself. Sent once per agent and step per run. The full line stays on your machine in `~/.dray/parse_failures.jsonl`.
- **A failed update install:** which step failed.
- **A screen that crashed:** React's error code and up to eight locations in Dray's own code. Not the message.

Other errors in the app's interface are not reported.

## Surveys

Now and then Dray may show a short survey card from PostHog, the analytics service it uses. With `DRAY_NO_ANALYTICS` set, no survey is loaded. A survey can be aimed at installs by the facts above and by how many sessions this install has. Answering is optional, and your answer goes to PostHog. Dismiss the card to skip it.

## Linux servers

A Dray server you install on Linux sends no analytics. The Mac app counts `server_added` and `server_connected` when you add or connect one, as described above.

When you start a session on another machine from the Mac app, the app sends that `session_started`, under your own install id, with `location` set to `remote` and `remote_os` set to `macos`, `linux` or `other`. The server's name, address and hostname are never sent. A Dray app on that other Mac does not count the session a second time. Sessions an agent starts there on its own are counted by that machine, or not at all on Linux.

## The website and these docs

drayhq.com and these docs count page views, plus clicks on the download, iPhone, sponsor and FAQ buttons and the switch between dark and light, in the same PostHog project. They set a PostHog cookie holding a random id, so repeat visits and moves between pages count as one visitor. Nothing ties that id to who you are, and signing in does not tell PostHog who you are. Click tracking and session recording are off.

PostHog keeps the IP address each visit comes from, and uses it to tell the country.

A page view carries the page's address. On your account pages that address holds your org's short name, such as `/app/your-org/servers`.

## Your Dray account

You sign in to the desktop app with a Dray account, in your browser on drayhq.com. The same account links your servers to an org. The iPhone and iPad app needs no account.

You sign in with GitHub, Google, or an email address and password. With GitHub or Google, they tell us your name, email address and profile picture. We ask for nothing else, and get no access to your repositories or other data there.

Your account holds:

| What | Why |
|---|---|
| Your name and email address | To sign you in, show who you are, and send you sign-in codes. |
| Your profile picture, from GitHub or Google | Shown beside your name on drayhq.com. |
| A username, made from your email address | Yours to change in your account settings. |
| A password, stored hashed, if you sign up with email | To sign you in. We never see the password itself. |
| Your orgs and who is in them | So members of an org can share its servers. |
| The machines you sign in on or link, by the name each gives itself | So you can see and unlink them. On a Mac this is its computer name. |
| The IP address and browser of each sign-in on the site | Saved with that sign-in. |

Sign-in codes reach you by email, sent through Bento.

Your account is kept apart from analytics. The desktop app's events carry its random install id, never your account, and the website never tells PostHog who you are.

### Change or delete your account

Change your name and username in your account settings on drayhq.com. To delete your account and everything it holds, email [support@drayhq.com](mailto:support@drayhq.com) from the address you sign in with. There is no delete button yet.

## The iPhone and iPad app

The Dray app for iPhone and iPad collects nothing. It has no analytics, no crash reporting, no ads and no account.

It talks to the Dray servers you add, and to nothing of ours. Your sessions, code and messages travel between the app and your own machines. Each server's address and token stay on your device, the token in the Keychain.

- **Dictation.** On iOS 26 and later, your speech can be turned into text on the iPhone itself. Or, when you pick your Mac in Settings › Dictation, the recording goes to the Dray server on your Mac, which turns it into text there. Either way, your voice never reaches us.
- **Camera.** Used only to scan a pairing QR code. The picture stays on the device.
- **Photos.** The app only adds pictures you choose to save. It never reads your library.
- **Other connections.** The app reads GitHub's public list of Dray releases, to tell you when a server is out of date. A picture in a transcript that points to a web address is loaded from that address. Links open in your browser.
- **Your Mac's count.** When the phone works through a Mac, the Mac app counts it the way it counts everything else on this page. A dictation from the phone is counted with where you dictated set to `phone`, and a task you start from the phone is counted as a session. Nothing else about it is sent.
- **Deleting your data.** We hold none from the app. Remove a server in Settings to forget it and its token on the device. Do that before you delete the app: iOS can keep Keychain items after an app is deleted.

## Other connections Dray makes

Besides analytics, Dray connects to the network for:

- **Your agents.** Each agent CLI talks to its own provider, as it does in a terminal. Dray also asks the session's own agent, on its cheapest model, to write each session's title from your first prompt. For fx, Dray reads Vercel's public model list to know each model's effort levels.
- **Updates.** Checking for and downloading new versions of the app and the `dray` CLI.
- **The changelog.** Reading what's new from drayhq.com.
- **Your Dray account.** Signing in through drayhq.com, and checking now and then that the sign-in still holds.
- **Downloads you trigger or need:** the Chromium framework for Dray's browser (from Spotify's CEF build server), dictation models (from Hugging Face).
- **GitHub and Linear,** when you use pull requests or issues, through `gh` or your Linear key.
- **OpenTunnel,** only while [Remote access](/reference/remote-access#remote-access) is on or a [public link](/reference/remote-access#share-a-dev-server) is live.

Dictation runs on your Mac. Your voice never leaves it, except when your iPhone sends a recording to your own Mac to be turned into text (see [The iPhone and iPad app](#the-iphone-and-ipad-app)).

## Services we use

- **PostHog** receives analytics from the desktop app and the website.
- **Vercel** hosts drayhq.com and these docs.
- **Railway** hosts the database that holds Dray accounts.
- **GitHub** and **Google** sign you in, when you choose them.
- **Bento** sends sign-in codes by email.
- **Dodo Payments** takes payments when you sponsor Dray. Your card details go to Dodo, never to us.

We sell no data, show no ads, and share nothing beyond these services.
