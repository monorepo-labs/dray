GitHub only takes images through its web editor. `dray upload` stores screenshots on drayhq.com and prints a markdown image line for each, ready to paste into a pull request body or comment. Agents can use it, and so can you.

```bash
dray upload before.png after.png
```

```
![before](https://…/3f1c…9a.png)
![after](https://…/8b02…4e.png)
```

The text in brackets is the file name without its extension.

## What it takes

- **PNG, JPEG, GIF or WebP**, up to 4 MB each. The site checks the file's bytes, not its name, so a renamed file of another kind is refused. SVG and video are not taken.
- **A GitHub account.** `dray upload` reads `GITHUB_TOKEN` when it is set, and otherwise asks `gh auth token`, so being signed in to the GitHub CLI is enough. The site asks GitHub who the token belongs to and then forgets it. The token is never stored or logged. A GitHub Actions token is refused, since it belongs to no user.
- **`curl`**, which macOS, Linux and Windows all ship.

Each file uploads on its own. One that fails is reported and the rest still upload; the command exits non-zero if any failed.

## Where the images live

Each image gets a public address named after a hash of its bytes. Uploading the same file twice gives the same address, and nothing can replace an image already uploaded. Anyone with the address can open it, so upload only what you would put in a public PR.

## Limits

- 4 MB per file.
- 30 uploads an hour and 200 a day per GitHub account.
- There is no delete. Ask in an issue to have an image taken down.

## Without the CLI

The CLI calls one endpoint, and `curl` can call it directly. The body is the raw file, and the token goes in a bearer header:

```bash
printf 'Authorization: Bearer %s' "$(gh auth token)" \
  | curl -sS -H @- --data-binary @after.png https://www.drayhq.com/api/upload
```

It answers `{"url": "…", "type": "image/png", "size": 48213}`. A refusal answers `401` for a missing or refused token, `413` for a file over 4 MB, `415` for a file that is not one of the four image types, and `429` past the rate limit.
